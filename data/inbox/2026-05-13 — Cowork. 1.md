## What is Claude Cowork?

Here’s the simplest analogy I have.

***Claude Chat*** is a very smart colleague who gives great advice. You describe the problem. They explain what to do. You go do it yourself.

***Claude Cowork*** is that same colleague, but now they have access to your computer, your files, your inbox, your notes, and your design tools. You describe the outcome you want. They handle it. You come back to finished work.

The technical term is ***AI agent***. You don’t need to remember that. What matters is the practical difference: Claude can now take action, not just suggest it.

Cowork launched in January 2026. It lives inside the Claude Desktop app on Mac and Windows. You need at least a Claude Pro plan ($17/month) to access it.

One thing to understand before we go further: the **real power** of Cowork isn’t any single use case. It’s what happens **when you chain connectors together**. Claude reading your Google Drive, saving the output to Notion, and uploading the design files to Canva, in one flow, without you switching between apps. That’s where this gets interesting, and I’ll show you exactly how I use it later in this article.

## How it’s different from Chat, Projects, and Claude Code

There are now four distinct ways to use Claude. They’re easy to confuse. They’re not the same thing.

***Claude Chat***

You ask, it answers. Claude has no access to your files or apps. You’re the one who executes everything it suggests.

***Claude Projects***

A folder inside Claude where you upload context and documents. Claude remembers what you’ve shared across conversations. Still question-and-answer mode. Claude advises. You act.

***Claude Cowork***

Claude has permission to access folders on your computer and to connect to external apps. You describe the task. Claude breaks it into steps, shows you the plan, waits for your approval, then does the work itself.

***Claude Code***

The same engine powering Cowork, but built for software developers writing and running code in a terminal (or Visual Studio, [check my other article on how to set it up](https://lucijatomsic.substack.com/p/claude-code-no-code-required)). ***Cowork is Claude Code for everyone else***. No terminal. No coding. Same capability, different audience.

One more concept worth knowing:

***Agent Skills***

These are pre-built instruction sets that tell Claude how to handle specific task types, like creating slide decks or writing reports. When you combine Skills with Connectors and folder access, Claude stops giving you advice and starts producing real outputs. I wrote about them in detail here:

## How to set it up

Setup takes about 15 minutes if you follow these steps in order.

**Step 1**

Download the Claude desktop app at [claude.ai/download](https://claude.com/download). This is different from the browser version. Cowork only works in the desktop app.

**Step 2**

Sign in with your Claude Pro account.

**Step 3**

You’ll see three tabs at the top: Chat, Code, and Cowork. Click Cowork.

## 6 use cases worth trying first

One connector each. One real task each. One copy-paste prompt each.

You don’t need all six. Start with the one that matches the task you’ve been putting off the longest.

### Use Case 1: Batch-summarize documents before a meeting

**Connector: Google Drive**

I use this before strategy sessions. Instead of spending an hour reading through every client document in a folder, I give Claude the folder and get a clean summary table back.

**Prompt:**

```markup
Summarize every file in [folder name]. For each one: main topic, 
key takeaways, any open action items. Format as a table with 
one row per file.
```

You come back to one table covering every document. No manual reading.

---

### Use Case 2: Weekly inbox triage

**Connector: Gmail**

Every Monday morning I used to spend 40 minutes going through emails that piled up over the weekend. Now I don’t.

**Prompt:**

```markup
Check my inbox from the last 7 days. List any email threads 
still waiting for my reply. For each one, write a short draft 
response I can review and send.
```

Claude comes back with a prioritized list of open threads and a draft reply sitting below each one. I review, edit if needed, and send.

---

### Use Case 3: Auto-save writing to Notion

**Connector: Notion**

This is how I currently use the Notion connector. Every piece of content I write gets saved directly into my Notion content database. Title, date, status tag, topic. Without me opening Notion once.

**Prompt:**

```markup
Save this draft to my [database name] in Notion. 
Title: [title]. Today's date. Status: Draft. Tag: [topic].
```

No copy-pasting between tools. The content exists in Notion the moment I tell Claude to save it. When I feel extra lazy, I even let Claude Cowork setup the whole Notion database for me

Other use cases with the same connector: turning messy meeting notes into structured briefs works just as well. Same setup, different prompt.

### Use Case 4: Fix things in your browser

**Connector: Claude in Chrome**

This one is different from every other connector on this list.

Claude doesn’t just read information from a connected app. It actually operates inside your browser. It navigates pages, reads what’s on screen, clicks buttons, and makes changes. It’s the most powerful use case here and the one that surprised me most.

For this one, you will need to install the Claude Chrome extension and grant access.

The honest caveat: it is slow.

Claude works step by step, methodically. Think of watching someone else use your computer remotely. You see every move. That slowness is also what makes it genuinely useful, because ***you can read its thinking*** as it goes.

Here’s my real example.

I created a website for my [charity](http://amaddata.com/) a while back, using a donation plugin. It had been broken for months. Visible on mobile. Completely invisible on desktop. I assumed a plugin update had introduced the bug and had given up on fixing it.

I gave Claude access to the site via Chrome. Described what I was seeing. Went on to eat lunch.

By the time I was finished, it had diagnosed a CSS conflict causing the issue, applied the fix, and left me a written summary of exactly what it changed and why. I learned more about my own website in that one session than in months of frustrated clicking.

**Prompt:**

```markup
I have an issue on my website [URL]. [Describe what you're seeing]. 
Investigate, explain what you find, and fix it if you can. 
Document every change you make and why.
```

### Use Case 5: Design, resize, organize, and log in one flow

**Connector: Canva (+ Notion to close the loop)**

I’m not a naturally structured person. Left to myself, my Canva account would be full of files named “ **final-FINAL-v3-USE-THIS-ONE.**”

So I don’t even try to manage it. Claude does.

Here’s how I actually use it: I create my designs as usual (actually Claude Cowork can also create designs if you describe what you want, I just like designing myself too much to hand this task over 😅). I describe to Claude what I did, what it’s for and what I need it to do. In my case, I want Claude to rename my designs in a way that makes sense, resize them into every format I need (social post, story, presentation slide) and download them to either my computer or my Google Drive.

Claude then organizes everything into a properly named folder with subfolders by format, and then reads that structure back to me so I always know where things are.

And here’s where it connects back to the Notion example: Claude can take those Canva file URLs and upload them directly into my Notion content database. One row per file, format labeled, date logged.

The design is done. Filed. Logged. Across two tools. Without me switching between a single app.

This is what I mean when I say connectors work together. One prompt can close a full loop.

**Prompt (Canva):**

```markup
Create a presentation in Canva based on [brief or content]. 
Resize it into [formats: e.g. 1080x1080, 1080x1920, 16:9 slide]. 
Organize everything into a folder called [name] with subfolders 
by format. List the URLs for each file when done.
```

**Follow-up prompt (to log in Notion):**

```markup
Take these Canva URLs and add them to my [database name] in Notion. 
One row per file. Include the format and today's date.
```

***Quick note:*** Claude in PowerPoint follows similar logic and is worth watching. Currently available on Team and Enterprise plans only, not yet on Pro.

### Use Case 6: Make sense of a spreadsheet

**Connector: Claude in Excel**

I don’t love spreadsheets. Claude does (or so it seems to me).

I use this when I have data I need to understand quickly but no time to build pivot tables or write formulas. I open the file in Excel, switch to Cowork, and ask Claude to do the analysis.

**Prompt:**

```markup
Open [file name]. Summarize the key trends. Flag anything that 
looks unusual or out of place. Give me one clear recommendation 
based on what you see.
```

Claude comes back with a plain-English summary and one specific recommendation. No formulas. No pivot tables. Just the answer.

## What Cowork can’t do yet

I want to be honest about this section, because the limitations are real and a few of them caught me off guard.

**No memory across sessions.**

Every new Cowork session starts fresh. Claude doesn’t remember what it did last time, which folders you gave it access to, or what connectors you set up previously. You need to give it context again each session. It’s a friction point, and Anthropic knows it.

**It only lives on one machine.**

***And that surprised me more than anything.*** I have two Macs (don’t ask). When I opened Cowork on my second one for the first time, everything was gone. No connectors installed. No folder access. Nothing 🤯. I had to set it up from scratch as if I’d never used it before. Your Cowork configuration does not sync across devices. It lives on one machine. If you switch computers often, factor that in.

**Not for sensitive or regulated data.**

Cowork activity isn’t yet captured in audit logs. Anthropic is explicit about this in their documentation. Don’t use it for confidential client files, GDPR-sensitive data, or anything regulated until that changes.

**Claude still pauses for your approval on significant actions.**

You can’t fully walk away on complex tasks. Claude checks in at key decision points before taking major actions. For most tasks this is fine. For long automated workflows, it means you need to stay loosely available.

These are research preview limitations, not permanent ones. The pace of updates since January has been fast.
