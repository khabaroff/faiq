# Как работает система

## Что ты делаешь

Кладёшь ссылку или файл в одно из двух мест:

**Очередь** — для URL и путей к файлам:
```
data/queue/inbox.txt
```
Просто добавь строку:
```
https://habr.com/ru/articles/...
https://youtube.com/watch?v=...
https://github.com/user/repo
/Users/ты/папка/статья.pdf
```

**Inbox** — для файлов напрямую:
```
data/inbox/
```
Положи туда `.md`, `.txt` или `.pdf`.

---

## Что происходит дальше

После запуска `python process_stream.py` каждый источник проходит три шага.

### Шаг 1 — Скачивание

Система смотрит на тип ссылки и выбирает способ:

| Что пришло | Как скачивается |
|---|---|
| Обычная статья | defuddle → Jina → HTTP |
| YouTube | youtube-transcript API |
| GitHub репозиторий | GitHub API + README |
| GitHub gist | GitHub API → Jina fallback |
| PDF файл | pdftotext |
| Локальный `.md`/`.txt` | читает напрямую |

Сырой текст сохраняется:
```
data/sources/2026-05-11_<hash8>/raw.txt
```

### Шаг 2 — Обработка через LLM

LLM (gpt-5.4) получает сырой текст и делает из него плотную заметку на русском.

Структура заметки:
```
# Заголовок
## Краткое изложение
## Ключевые идеи
## Детали
## Код и примеры
## Сущности
## Концепции
## К изучению
```

Параллельно второй LLM (gpt-5.4-mini) вытаскивает теги, топики, entity, концепции.

### Шаг 3 — Сохранение в вики

Готовая заметка кладётся в:
```
wiki/extracts/
  articles/     ← статьи и заметки
  youtubes/     ← видео
  githubs/      ← репозитории
  notes/        ← локальные файлы
  pdfs/         ← PDF
```

Метаданные источника:
```
data/sources/2026-05-11_<hash8>/meta.json
```

Индексы обновляются автоматически:
```
wiki/_indexes/by-topic.md
wiki/_indexes/by-kind.md
wiki/_indexes/recent.md
```

---

## Что происходит с inbox.txt

После обработки строка в `inbox.txt` меняется:
- успех → `#done# https://...`
- ошибка → `#failed# 2026-05-11T... причина | https://...` в `needs_review.txt`

Уже обработанные (`#done#`) пропускаются при следующем запуске.

---

## Дерево файлов

```
data/
  queue/
    inbox.txt          ← сюда добавляешь URL
    needs_review.txt   ← сюда попадают ошибки
  sources/
    2026-05-11_abc123/ ← по одной папке на источник
      raw.txt          ← исходный текст
      meta.json        ← статус, теги, тип
  inbox/               ← файлы кладёшь сюда
  logs/
    pipeline.log       ← всё что происходило + стоимость LLM

wiki/
  extracts/            ← готовые заметки (открывай в Obsidian)
  _indexes/            ← автоматическая навигация
```
