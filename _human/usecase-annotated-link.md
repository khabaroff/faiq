# Кейс: ссылка + мой комментарий

## Задача

Ты нашёл статью, хочешь её сохранить и добавить свои мысли к ней.
Например: ссылка + пара абзацев «зачем мне это, что я из этого взял».

---

## Куда класть

`data/inbox/` — папка для файлов.

Создай файл `.md`, например:
```
data/inbox/my-note-about-article.md
```

---

## Как написать файл

```markdown
https://habr.com/ru/articles/12345/

Нашёл через коллегу. Хорошо объясняет почему X лучше Y в условиях Z.
Особенно интересен раздел про edge cases — надо применить в проекте.
Вернуться когда буду делать рефакторинг модуля X.
```

**Правило:** URL должен стоять на отдельной строке. Комментарий — 20+ символов (иначе система не увидит, что это смешанный файл).

---

## Что произойдёт

Система классифицирует файл как **mixed** — ссылка + текст.

Это значит **два результата**:

### 1. Статья по ссылке
Система скачает `https://habr.com/...` и сделает из неё заметку:
```
wiki/extracts/articles/<slug-статьи>.md
```

### 2. Твоя заметка как отдельная страница
Весь твой файл (URL + комментарий) тоже пройдёт через LLM и станет страницей:
```
wiki/extracts/notes/my-note-about-article.md  (или articles/)
```

Там будет твой комментарий, переработанный в структуру с заголовком и разделами.

---

## Если нужна только ссылка без заметки

Просто добавь URL в очередь:
```
data/queue/inbox.txt
```
Одной строкой:
```
https://habr.com/ru/articles/12345/
```

---

## Если нужна только заметка без обработки ссылки

Напиши ссылку **в теле текста** (не на отдельной строке):

```markdown
Нашёл хорошую статью (https://habr.com/ru/articles/12345/) через коллегу.
Объясняет почему X лучше Y. Надо применить в проекте.
```

Тогда система обработает только твой текст — ссылка будет внутри заметки, но отдельно скачиваться не будет.

---

## Итог

| Что написал | Куда класть | Что получишь |
|---|---|---|
| Только URL | `inbox.txt` или `data/inbox/file.md` с одним URL | Заметка по статье |
| URL + комментарий (URL на отдельной строке) | `data/inbox/file.md` | Заметка по статье + заметка по твоему тексту |
| Только текст (без URL на отдельной строке) | `data/inbox/file.md` | Заметка по твоему тексту |
